Ptty PC Monitor 설치 방법 (Windows 10/11)
=========================================

준비물
------
- Stream Deck 앱 7.1 이상
- 이 폴더 전체 (압축을 먼저 풀어 주세요. 압축 파일 안에서 바로 실행하면 안 됩니다.)


1. 센서 서비스 설치
-------------------
install-service.cmd 를 더블클릭하고, UAC 창에서 "예"를 누릅니다.
- C:\Program Files\Ptty PC Monitor 에 설치되고, 부팅할 때마다 자동으로 실행됩니다.
- 설치가 끝나면 현재 CPU / GPU / RAM 값이 창에 표시됩니다.
- "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누릅니다
  (서명되지 않은 개인 제작 프로그램이라 표시되는 경고입니다).


2. Stream Deck 플러그인 설치
----------------------------
com.hollobar.ptty-pc-monitor.streamDeckPlugin 을 더블클릭합니다.
Stream Deck 앱이 열리면서 설치 여부를 묻습니다. "설치"를 누릅니다.
이후 오른쪽 액션 목록의 "Ptty PC Monitor" 아래에서 다음 액션을 끌어다 놓습니다.
- 센서 표시: 일반 버튼
- 모니터 밝기: Stream Deck + 다이얼


3. (필요할 때만) PawnIO 드라이버
--------------------------------
CPU 온도와 메인보드 팬(CPU 팬, 케이스 팬)을 읽으려면 PawnIO 드라이버가 필요합니다.
나머지 값(GPU, 사용량, RAM, 인터넷 속도, Kraken 같은 USB 쿨러)은 없어도 표시됩니다.
- 드라이버가 없으면 CPU 온도 버튼에 "PawnIO 필요"라고 표시되고,
  버튼 설정 화면에 설치 안내가 나옵니다.
- https://pawnio.eu 에서 설치하면 1분 안에 자동으로 인식됩니다.
- LibreHardwareMonitor 최신 버전을 설치한 적이 있으면 이미 설치되어 있을 수 있습니다.


언어
----
Stream Deck 앱의 언어(기본적으로 Windows 언어를 따름)에 맞춰 표시됩니다.
한국어이면 한국어로, 그 외에는 영어로 표시됩니다.


제거
----
- 서비스: uninstall-service.cmd 를 실행합니다.
- 플러그인: Stream Deck 앱 → 설정 → 플러그인 → Ptty PC Monitor → 제거


다른 PC로 옮길 때 참고
----------------------
- 버튼 배치와 설정은 Stream Deck 앱의 프로필 내보내기 / 가져오기로 옮길 수 있습니다.
- 배경 이미지는 PC에 저장된 파일 경로로 기억됩니다.
  새 PC에서는 이미지를 다시 골라 주세요 (같은 경로에 파일이 있으면 그대로 쓰입니다).
- 고른 글꼴이 새 PC에 없으면 기본 글꼴로 표시됩니다.
- 모니터 밝기는 모니터 OSD 메뉴에서 DDC/CI가 켜져 있어야 동작합니다.
