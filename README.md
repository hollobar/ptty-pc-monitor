# Ptty PC Monitor (Stream Deck 플러그인)

LibreHardwareMonitor나 NZXT CAM 없이 Stream Deck 버튼에 다음 값을 표시합니다.

- CPU 온도, CPU 사용량
- GPU 온도, GPU 사용량
- RAM 사용량
- 인터넷 다운로드/업로드 속도
- 팬 / 펌프 RPM (메인보드 팬 헤더, GPU 팬, NZXT Kraken 펌프·라디에이터 팬)

Stream Deck + 다이얼로는 모니터 밝기와 명도(대비)를 조절할 수 있습니다. Monitorian과 같은 DDC/CI 방식입니다.

## 구성

```
service/   센서 서비스 (C# / .NET 10, LibreHardwareMonitorLib 사용)
helper/    플러그인 보조 프로그램 (C# / .NET 10): 모니터 DDC/CI 제어, 배경 이미지(GIF/WebP) 디코딩
plugin/    Stream Deck 플러그인 (TypeScript, @elgato/streamdeck)
scripts/   서비스 설치/제거 스크립트
dist/      빌드 결과물 (service 실행 파일, 배포용 .streamDeckPlugin)
```

- **센서 → 서비스:** CPU 온도와 메인보드 팬은 관리자 권한과 커널 드라이버(PawnIO)가 있어야 읽을 수 있습니다. Stream Deck 플러그인은 일반 권한으로 실행되므로 이 값을 직접 읽을 수 없습니다.
  그래서 센서를 읽는 일은 **Windows 서비스**(LocalSystem 권한, 부팅 시 자동 시작)가 맡습니다.
  플러그인은 서비스가 내 PC 안에서만 접근 가능한 주소(`http://localhost:47321/api/sensors`)로 내보내는 값을 1초마다 받아서 표시합니다.
- **모니터 밝기 → helper:** DDC/CI는 로그인한 사용자 세션에서만 동작해서, 서비스(세션 0)에서는 할 수 없습니다.
  그래서 플러그인이 `pcmonitor-helper.exe`를 직접 실행해서 사용합니다. 이 프로그램은 플러그인의 `bin` 폴더에 들어 있습니다.

## 설치

1. **서비스 설치**: `scripts\install-service.cmd`를 더블클릭하고 UAC 창에서 **예**를 누릅니다.
   - 파일이 `C:\Program Files\Ptty PC Monitor`로 복사되고, 서비스 `PcMonitorService`가 등록·시작됩니다.
   - 이미 설치되어 있으면 새 버전으로 교체됩니다.
2. **Stream Deck**: 오른쪽 액션 목록의 **Ptty PC Monitor** 아래에서 액션을 끌어다 놓습니다.
   - **센서 표시**: 일반 버튼용
   - **모니터 밝기**: Stream Deck + 다이얼용
3. **(필요할 때만) PawnIO 드라이버**: CPU 온도와 메인보드 팬에만 필요합니다. 설치를 강요하지 않습니다.
   - 드라이버가 없으면 CPU 온도 버튼에 **"PawnIO 필요"**라고 표시됩니다.
   - 버튼 설정 화면에는 짧은 설명과 **pawnio.eu 열기** 버튼이 나옵니다.
   - https://pawnio.eu 에서 설치하면 서비스가 1분 안에 알아서 인식합니다. 이 PC에는 이미 설치되어 있습니다.

제거할 때는 `scripts\uninstall-service.cmd`를 실행합니다.

## 언어

한국어와 English를 지원합니다.

- Stream Deck 앱의 언어(기본적으로 Windows 언어를 따름)에 맞춰 자동으로 표시됩니다. 따로 고르는 메뉴는 없습니다.
  - 한국어이면 한국어, 그 외 언어는 모두 영어로 표시됩니다.
- **번역되는 곳:** 버튼 글자, 다이얼 화면, 설정 화면, 배치 창, 액션 이름과 설명, 설치 스크립트 메시지(Windows 표시 언어 기준), 설치 안내(`INSTALL.txt` 영어 / `INSTALL.ko.txt` 한국어)
- **기본 글꼴:** 한국어는 맑은 고딕, 영어는 Segoe UI가 먼저 쓰입니다.
- **번역 수정:** 번역은 `plugin/locales/ko.json`, `en.json` 두 파일에만 있습니다. 빌드하면 Stream Deck용 언어 파일과 설정 화면용 `ui/locales.js`가 자동으로 만들어집니다.

## 센서 표시 (버튼)

### 설정
- **표시 항목**을 고릅니다. 팬 / 펌프 RPM을 고르면 어떤 팬을 표시할지 고르는 칸이 나타납니다.
- **RAM 표시 (RAM만):**
  - **크게 표시할 값**: **사용률 (%)**(기본, `51%` + 아래 `16.3 / 32GB`) 또는 **사용량 (GB)**(`16.3GB` + 아래 `51% / 32GB`)
  - **보조 줄 크기**: 보조 줄 글자 크기를 값과 따로 정합니다. 비우면(자동) 값 크기에 맞춰 바뀝니다.
  - **보조 줄**: 끄면 큰 값만 표시합니다.
- **팬 표시 단위 (팬만):** **회전수 (RPM)**(기본) 또는 **백분율 (%)**(팬 작동률, 팬 제어 센서가 있는 팬만)
- **이름**: 버튼 위쪽에 표시할 글자를 직접 정할 수 있습니다.
  - 메인보드 팬은 "Fan #2"처럼 일반적인 이름으로 나오므로, 여기서 "CPU 팬" 같이 바꿔 쓰면 편합니다.

### 글자 (글꼴 · 크기 · 위치)
- **항목 글꼴 / 값 글꼴:** PC에 설치된 글꼴 중에서 고릅니다.
  - 고른 글꼴에 없는 글자(예: 한글)는 기본 글꼴로 대신 표시됩니다.
- **항목 크기 / 값 크기:** 슬라이더나 숫자 칸으로 조절합니다. ↺를 누르면 "자동"으로 돌아갑니다.
  - 자동일 때는 글자 길이에 따라 크기가 조절됩니다.
  - 단위(°C, %)와 아래 보조 줄은 값 크기에 맞춰 함께 커지고 작아집니다.
### 배치 창
**배치 창 열기**를 누르면 새 창이 뜹니다. 창 아래쪽 버튼으로 무엇을 옮길지 고릅니다. 바꾼 내용은 자동으로 저장됩니다.

| 모드 | 조작 | 숫자 입력 |
|---|---|---|
| 항목 이름 / 값 | 끌어서 이동, 오른쪽 아래 손잡이를 아래로 끌면 커지고 위로 끌면 작아짐, 마우스 휠로 1씩. 값 모드에서는 **큰 값**(RAM은 **사용량**)과 **보조 줄**(예: RAM `16.3 / 32GB`)을 따로 배치하고 크기도 따로 조절 | X, Y, 크기 (비우면 자동) |
| 그래프 | 파란 영역을 끌어서 이동, 흰 손잡이로 위·아래·왼쪽·오른쪽 끝 조절 | 위(최고), 아래(최저), 왼쪽, 오른쪽 |
| 배경 이미지 | 끌어서 이동, 모서리 손잡이나 마우스 휠로 확대/축소 | X 이동, Y 이동, 크기 % |
| 자르기 | 이미지 전체를 보여 주고, 흰 테두리 안쪽만 사용. 테두리를 끌어 이동, 손잡이 8개로 크기 조절 | 왼쪽·위·오른쪽·아래 % |

- **공통:**
  - 방향키로 1px, Shift+방향키로 5px씩 옮길 수 있습니다.
  - 숫자 칸 위에서 마우스 휠을 굴려도 값이 바뀝니다.
  - **X축 가운데 / Y축 가운데** 버튼은 고른 항목의 가운데를 버튼의 가로·세로 중심선(72)에 맞춥니다. 항목 이름, 값, 배경 이미지에서 쓸 수 있습니다.
    - 글자는 보이는 글자 영역의 가운데를 기준으로 맞춥니다. 값은 아래 보조 줄까지 포함합니다.
  - **기본값** 버튼을 누르면 고른 항목만 원래대로 돌아갑니다.
- **그래프:**
  - **위** 선은 그래프 최고치(최대값)가 닿는 높이이고, **아래** 선은 최저치(최소값)가 놓이는 높이입니다.
  - 기본은 위 70, 아래 144로, 버튼의 아래쪽 절반입니다.
  - 빠른 설정 버튼: 전체 너비, 아래 절반, 버튼 전체
- **글자 크기:**
  - 값 크기를 바꾸면 단위(°C, %)와 보조 줄도 같은 비율로 커지고 작아집니다.
  - **크기 자동**을 누르면 글자 길이에 맞춰 크기를 정하는 자동으로 돌아갑니다.
  - 배치 창에서 바꾼 크기는 설정 화면의 항목 크기 / 값 크기 슬라이더에도 반영됩니다.
- **자르기:**
  - 이미지의 일부만 쓰고 싶을 때 사용합니다. 자른 부분을 기준으로 배경 이미지 모드의 위치와 크기가 적용됩니다.
  - **자르기 해제**: 이미지 전체를 씁니다.
  - **정사각형 (가운데)**: 이미지 가운데를 정사각형으로 자릅니다.
- **배경 이미지:**
  - 100%는 버튼을 꽉 채우는 크기입니다. 10~500% 사이로 조절할 수 있습니다.
  - 버튼 밖으로 나간 부분은 흐리게 보입니다.
  - 이미지를 100%보다 작게 줄이면 남는 부분에 배경색이 보입니다.
- **보조 줄:** 단위, RAM 상세 같은 보조 줄은 기본적으로 값을 따라 움직입니다. 보조 줄을 직접 끌면 그 위치에 고정되고, **보조 줄을 값에 붙이기**로 다시 따라오게 할 수 있습니다.
- **배치 초기화:** 설정 화면에서 누르면 이름·값의 위치와 크기, 그래프, 배경 이미지의 위치·크기·자르기가 모두 기본값으로 돌아갑니다.

### 슬라이더
모든 슬라이더(채움 진하기, 글자 크기, 이미지 어둡게, 다이얼 변화량)는 이렇게 조절할 수 있습니다.
- 오른쪽 숫자 칸에 현재 값이 표시되고, 직접 입력해서 바꿀 수 있습니다.
- 슬라이더 위에서 **마우스 휠**을 굴리면 1씩 바뀝니다.
- ↺ 버튼을 누르면 기본값으로 돌아갑니다.

### 그래프 범위
- **최소 / 최대**를 입력하면 그 범위를 그래프 높이 전체로 씁니다. 비워 두면 기본값을 씁니다.
  - 예) CPU 온도 최소 40, 최대 90 → 40°C가 바닥, 90°C가 꼭대기
- **그래프 단위:** 항목에 따라 **백분율 (%)** 또는 **실제 값**을 고릅니다.
  - **백분율 (%)**: 0~100 사이로만 입력됩니다(음수 → 0, 100 초과 → 100).
  - **실제 값**(°C / GB / RPM / Mbps): 입력 범위에 제한이 없습니다.
  - 칸이 비어 있을 때 마우스 휠을 굴리면 최소는 0부터, 최대는 백분율이면 100부터(실제 값이면 기본 최대값부터) 움직입니다.

| 항목 | 고를 수 있는 단위 (첫 번째가 기본) | 기본 범위 |
|---|---|---|
| CPU / GPU 온도 | °C, % (0~100) | 0~100 |
| CPU / GPU 사용량 | % 만 | 0~100 |
| RAM | % (사용률), GB (사용량) | 0~100% / 0~전체 용량 |
| 인터넷 다운로드 / 업로드 | Mbps 만 (항상 실제 값, 제한 없음) | 최근 30초 최대값에 맞춰 자동 |
| 팬 | RPM, % (팬 작동률) | RPM은 자동, %는 0~100 |

### 색상
- **항목 글자:** 위쪽 이름과 아래쪽 보조 글자의 색
- **자동 색상** (기본값 켜짐): 숫자와 그래프 색이 값에 따라 바뀝니다. 초록(정상) → 노랑(주의) → 빨강(높음)
  - CPU 온도: 70°C부터 노랑, 85°C부터 빨강
  - GPU 온도: 70°C부터 노랑, 83°C부터 빨강
  - 인터넷 속도와 팬은 파란색으로 고정됩니다.
- 자동 색상을 끄면 **숫자**, **그래프 선**, **그래프 채움** 색을 직접 고를 수 있습니다.
- **채움 진하기:** 그래프 아래쪽 채움 영역의 불투명도

### 배경
- **배경색**을 고를 수 있습니다.
- **배경 이미지**: PNG, JPEG, BMP, GIF, WebP 파일을 쓸 수 있습니다.
  - 움직이는 GIF와 WebP는 버튼에서도 움직입니다. 최대 300프레임, 초당 약 15프레임으로 재생됩니다.
  - 이미지는 가운데 기준으로 정사각형으로 잘려서 들어갑니다.
  - **이미지 어둡게:** 이미지 위에 검은 막을 씌워서 글자가 잘 보이게 합니다.
  - 이미지를 빼려면 **이미지 제거**를 누릅니다.

### 버튼 상태

| 표시 | 의미 |
|---|---|
| 연결 중… | 첫 데이터를 기다리는 중 |
| 서비스 꺼짐 | 서비스가 설치되지 않았거나 중지됨 |
| PawnIO 필요 | PawnIO 드라이버가 없어 CPU 온도(또는 메인보드 팬)를 못 읽음. 버튼 설정 화면에 설치 안내가 나옴 |
| 관리자 권한 필요 | 서비스가 관리자 권한 없이 실행되어 CPU 온도를 못 읽음 |
| 센서 없음 / 팬 센서 없음 | 하드웨어에서 해당 센서를 찾지 못함 |

배경 그래프는 최근 30초 동안의 값입니다.

## 모니터 밝기 (Stream Deck + 다이얼)

| 조작 | 동작 |
|---|---|
| 돌리기 | 밝기(또는 명도) 조절. 한 칸당 변화량은 설정에서 1~10으로 바꿀 수 있습니다 (기본 2) |
| 누르기 | 밝기 ↔ 명도 전환 |
| 화면 터치 | 모니터에서 현재 값을 다시 읽기 (모니터 버튼으로 값을 바꿨을 때) |

- 설정에서 **모니터**를 고릅니다.
  - **모든 모니터**를 고르면 모든 모니터가 같은 만큼 함께 움직입니다.
  - 특정 모니터 하나만 고를 수도 있습니다.
- 이 PC에서 확인한 모니터: MSI MAG 274Q X24, LG 27GL850
- 모니터 OSD 메뉴에서 **DDC/CI가 켜져 있어야** 합니다. 지원하지 않는 모니터는 목록에 "(DDC/CI 미지원)"으로 표시됩니다.

## 다른 PC에 설치하기

### 설치 파일 만들기 (이 PC에서)

```bash
powershell -ExecutionPolicy Bypass -File scripts/build-package.ps1
```

- 서비스, helper, 플러그인을 모두 다시 빌드합니다. 결과물은 아래 두 가지입니다.
  - `dist/PttyPCMonitor-Setup/` 폴더
  - `dist/PttyPCMonitor-Setup.zip` (GitHub Releases에 올릴 파일)
- 코드를 바꾼 뒤에는 이 명령을 다시 실행하면 됩니다.
- Release 빌드에는 디버그 정보와 개발 PC의 폴더 경로가 들어가지 않습니다.

설치 파일 구성:

| 파일 | 설명 |
|---|---|
| `com.hollobar.ptty-pc-monitor.streamDeckPlugin` | Stream Deck 플러그인. 더블클릭하면 설치됨 (helper 포함) |
| `service/` | 센서 서비스 (.NET 포함, 따로 설치할 것 없음) |
| `install-service.cmd` / `uninstall-service.cmd` | 서비스 설치 / 제거 |
| `INSTALL.txt` / `INSTALL.ko.txt` | 다른 PC에서 볼 설치 안내 (영어 / 한국어) |
| `THIRD-PARTY-NOTICES.md` | 포함된 오픈소스 구성 요소의 라이선스 고지 |

### 다른 PC에서

1. zip 파일의 압축을 풉니다.
2. CPU 온도와 메인보드 팬이 필요하면 https://pawnio.eu 에서 PawnIO를 설치합니다.
3. `install-service.cmd`를 실행하고 UAC 창에서 **예**를 누릅니다.
4. `com.hollobar.ptty-pc-monitor.streamDeckPlugin`을 더블클릭해서 플러그인을 설치합니다.

자세한 내용은 압축 파일 안의 `INSTALL.ko.txt`(한국어), `INSTALL.txt`(영어)에 있습니다.

### 주의

- **이 개발 PC에는 `.streamDeckPlugin` 파일을 설치하지 마세요.** 개발 폴더가 이미 같은 이름으로 연결(link)되어 있어서 서로 충돌합니다.
- 버튼 배치는 Stream Deck 앱의 프로필 내보내기 / 가져오기로 옮길 수 있습니다.
  - 배경 이미지는 파일 경로로 기억되므로, 새 PC에서 다시 골라야 합니다.

## 개발

### 서비스

```bash
dotnet publish service/PcMonitor.Service -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist/service
```

- `dist/service/appsettings.json`에서 바꿀 수 있는 항목:
  - `Port`: 포트. 바꾸면 `plugin/src/sensor-client.ts`의 주소도 같이 바꿔야 합니다.
  - `UpdateIntervalMs`: 갱신 주기
  - `EnableControllers`: NZXT Kraken 등 USB 컨트롤러 읽기. NZXT CAM과 충돌하는 것 같으면 `false`로 바꿉니다.
- 다시 빌드한 뒤에는 `install-service.cmd`를 다시 실행하면 새 버전으로 교체됩니다.
- 센서 이름을 확인할 때: http://localhost:47321/api/sensors/all

### helper (모니터 제어 / 이미지 디코딩)

```bash
dotnet publish helper/PcMonitor.Helper -c Release -o plugin/com.hollobar.ptty-pc-monitor.sdPlugin/bin
```

- 결과물 `pcmonitor-helper.exe`는 플러그인의 `bin` 폴더에 들어갑니다. 플러그인을 배포할 때 같이 포함됩니다.
- 이미지 디코딩에는 SkiaSharp(MIT 라이선스)를 사용합니다.

### 플러그인

```bash
cd plugin && npm install
```
```bash
cd plugin && npm run watch
```

- `npm run watch`는 코드를 수정할 때마다 자동으로 다시 빌드하고 플러그인을 재시작합니다.
- 플러그인은 이미 Stream Deck에 링크되어 있습니다. 다시 링크해야 하면 `npm run link`를 실행합니다.
- 배포 파일 만들기: helper를 publish한 뒤 `npm run pack` → `dist/com.hollobar.ptty-pc-monitor.streamDeckPlugin`
